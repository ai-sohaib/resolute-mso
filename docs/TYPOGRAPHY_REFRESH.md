# Typography Refresh

Reference direction: a clean, modern healthcare navigation style similar in visual weight and spacing to MedCare MSO, while retaining Resolute MSO branding and structure.

## Applied treatment

- Manrope for interface and content typography with system-font fallbacks.
- Navigation links reduced from heavy bold styling to a refined medium weight.
- Improved header spacing, alignment, hover states, dropdown rhythm, and mobile menu typography.
- Existing colors, content, routes, logo, calls to action, and page structure remain unchanged.
