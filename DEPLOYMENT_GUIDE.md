# Deployment Guide

1. Open the GitHub repository named `resolute-mso`.
2. Upload the ZIP contents directly into the repository root. Do not upload an extra nested folder.
3. Confirm these files are visible at the root: `index.html`, `CNAME`, `sitemap.xml`, `assets/`, `content/`, and `supabase/`.
4. Go to Settings > Pages.
5. Set Source to `Deploy from a branch`.
6. Select `main` and `/root`.
7. Save and wait for GitHub Pages to publish.
8. Visit https://www.resolutemso.com.

The included CNAME contains exactly:

```
www.resolutemso.com
```
