# Google & Bing Indexing Checklist

## Google Search Console
- Property: resolutemso.com domain property
- Sitemap: https://www.resolutemso.com/sitemap.xml
- Check Pages report weekly
- Use URL Inspection for new pages
- Request indexing for new high-priority landing pages and blogs

## Bing Webmaster Tools
- Import from Google Search Console
- Confirm sitemap imported
- Manually submit sitemap if needed:
  https://www.resolutemso.com/sitemap.xml
- Use URL Inspection for new pages

## New Page Launch Checklist
- Page opens at live URL
- Canonical URL is correct
- Page appears in sitemap.xml
- Page appears in llms.txt if important
- Internal links point to page
- Form/CTA works
- Mobile layout checked
- URL submitted to Google and Bing
